# Проверки версии with-tablet — 2026-09-21

## Выполнено локально

- Python 3.12: **71 unittest**, ошибок нет; compileall и загрузка двух YAML
  конфигураций успешны. Есть HTTP-проверка `/v1/weight`, повторного packetId,
  истечения свежести, сохранения тары/яркости, независимости экрана от API,
  меню/PIN, порядка TLC-битов и калибровки.
- Android: `build.ps1 -Test` с JDK 21, Android SDK 36 — **BUILD SUCCESSFUL**,
  **17 тестов**, ошибок нет; debug APK `0.6.0-with-tablet`, versionCode 7.
  SQLite через Robolectric: очередь двух автономных заданий, повторное открытие,
  подтверждение создания без потери событий, стабильный порядок задач и кеш.
- Backend: `loader-tasks-test.mjs`, `loader-terminals-test.mjs`,
  `with-tablet-test.mjs`, `host-current-pointer-test.mjs` — PASS.
  Изолированные SQLite-фикстуры; реальные production-данные не использованы.
  Проверены подпись и привязка плана, удаление исходного рациона, два задания,
  повторные UUID, конфликт калибровки, исходный вес в inbox и обработанной записи.
- Проверки синтаксиса изменённого JS и `git diff --check` успешны.

## Не выполнено без оборудования / отдельного стенда

- GPIO, электрические уровни/токи, нагрев TLC/LED, АЦП и реальная точность.
- Физический Android: одновременные Wi-Fi/LTE, поведение USB-роутера,
  читаемость интерфейса, перчатки, вибрация, сохранение при потере питания.
- Полный прогон нового протокола на отдельном PostgreSQL-инстансе и нагрузка
  HOST 2 Гц. Серверный адаптер использует прежнюю схему и общий reducer,
  но тесты SQLite не доказывают корректность production PostgreSQL-развёртывания.
- Production deployment, release signing, kiosk/Device Owner.

Перед работой на машине пройти checklist в [WITH_TABLET.md](WITH_TABLET.md).
