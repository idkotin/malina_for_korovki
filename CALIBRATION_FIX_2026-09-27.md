# Полевая проверка нуля

Пользователь подтвердил питание возбуждения 4.95 В исправным прибором; прежние 6.22–6.28 В были показаниями прибора с разряженной батарейкой. Подключение заявлено Ex+→AVDD, Ex−→AVSS, SIG+→IN0, SIG−→IN1, штатный терминал отключён. Это не приёмка качества питания или проводки под вибрацией.

Причина Err в журнале — Unstable calibration load. Две серии усреднённых отсчётов ADC2: медианы 2731.67/2757.33, размахи 370.17/232.33. Старый допуск max(10, abs(median)*0.002) равнялся 10; он не учитывал наблюдаемый шум при первоначальном нуле.

Изменения: 20 усреднённых чтений вместо 5 (порядка 5 с при нынешнем времени чтения); для standalone ADC2 минимальный допуск размаха 500 отсчётов. Это предварительный полевой допуск, не заявленная точность 5 кг. Дополнительно сравниваются медианы первых/последних 5 чтений: предел max(20, 3*1.4826*MAD/sqrt(5)); движение с выраженным дрейфом отклоняется. Нефинитные значения и выбросы по размаху отклоняются. Журнал содержит медиану, размах, дрейф и допуски.

При span изменение относительно нуля должно превышать max(10, 10*max(zero_range,span_range)). Малая нагрузка относительно шума не подтверждает калибровку. Это минимальная проверка отношения сигнала к шуму, не гарантия точности. После span требуется контроль известной нагрузкой и оценка шума уже в кг.

Повторная неудачная попытка zero удаляет старый неподтверждённый zero, но не меняет сохранённую рабочую калибровку. Zero остаётся в памяти: между zero и span нельзя перезапускать Pi/сервис. По одному zero валидный вес не выдаётся; прочерки после успешного zero до span ожидаемы. Во время сбора ждать, не нажимать повторно кнопки и не менять нагрузку.

Проверка: 75 unittest, включая точную вторую полевую серию, недостаточный/достаточный span, дрейф, выброс, NaN и сохранность предыдущей калибровки. Аппаратный результат новой версии ещё должен подтвердить пользователь.

Установка без изменения config/calibration:

```bash
cd /opt/host-monitor
git pull --ff-only origin with-tablet && sudo systemctl restart host-monitor
sudo journalctl -u host-monitor --since "2 minutes ago" --no-pager -n 15
```
