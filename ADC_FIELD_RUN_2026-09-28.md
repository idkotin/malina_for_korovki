# Проверка ADC1, ADC2 и штатного терминала

## Сохранение
У ADC1 и ADC2 отдельные коэффициенты и отдельный захваченный пустой ноль.
Можно переключаться и штатно перезапускать питание между нулём и нагрузкой.
Новый неудачный захват нуля отменяет предыдущий подготовленный ноль своего ADC,
но не портит действующие коэффициенты. Успешная нагрузочная калибровка потребляет
подготовленный ноль. После изменения схемы/датчиков старый ноль нужно снять заново.
Калибровка ADC1 не исправляет и не меняет ADC2: он остаётся контрольным старым вариантом.

## Кнопки нашего терминала
Вход: плюс и минус одновременно 3 с. Цифры PIN менять плюс/минус, короткий NETT —
следующая цифра. После входа подтверждение действия — NETT 2 с.

| PIN | Действие |
| --- | --- |
| 7229 | Выбрать AdC 1 или AdC 2 плюс/минус, подтвердить |
| 7230 | Только ADC1: известный полный вес содержимого; 0 только на пустом |
| 7227 | Сохранить пустой ноль для последующей калибровки выбранного ADC |
| 7228 | Известный полный вес после сохранённого пустого нуля выбранного ADC |

Масса: короткое плюс/минус по 5 кг, удержание ускоряет. При сборе будут прочерки,
сбор около 6–7 с, нагрузку не менять. Err означает отказ: не считать точку принятой.
7230 с нулём сразу выставляет ADC1 ноль и сохраняет точку для будущего 7228.
7227 только готовит точку, до 7228 действующая калибровка остаётся прежней.
Обычная NETT — локальная тара табло. Перед сравнением снять её удержанием NETT
2 с именно в обычном экране веса, вне меню. Сравнивать полный вес содержимого,
а не добавленную порцию, не массу самого кузова и не значение после случайной тары.

## Переподключение
ADC1 ↔ ADC2 переключаются кнопками, проводов не трогать. Штатный ↔ наш — перенос
целого разъёма датчиков. Не соединять два питания моста одновременно. Перестыковку
делать при отключённом питании измерительной части; кнопка экрана не снимает питание
моста. Если отключается сама Raspberry Pi, предварительно выполнить sudo poweroff,
дождаться выключения и затем снимать питание. Резкие отключения уже повреждали Git.
После подключения дождаться устойчивого показания, записать диапазон за 10–15 с.
Не обнулять штатный терминал при включении с грузом; нужен сохранённый пустой ноль.
Если штатный сам обнуляется под грузом, такой результат не годится как эталон.

Все три показания в одной строке сравнения снимать на том же месте, без движения,
загрузки и выгрузки между ними. Ноль и нагрузочную точку желательно снимать на ровном
основании при одинаковом состоянии двигателя/мешалки, для этой проверки — выключены.
Работу с включённой мешалкой проверить отдельно, не обнуляя возникшее смещение.

## Заезд
1. Сейчас, с грузом: на штатном записать полную массу. Перенести разъём на наш,
   выбрать 7229 → AdC 1, затем 7230 → эта масса. Получится временная привязка
   со старым масштабом ADC2. Совпадение именно в этой точке ещё не проверка точности.
2. После полной выгрузки: проверить пустой кузов, подключить наш, AdC 1,
   7230 → 0. Это сразу ноль и подготовка двухточечной калибровки. Записать ADC1,
   переключить ADC2 и записать его, вернуться на ADC1. ADC2 не обнулять ради сравнения.
3. Доехать до кучи с ADC1. В движении ноль не нажимать, качку отдельно отметить.
4. Остановиться, подключить штатный, загрузить промежуточную порцию. Записать
   штатный полный вес, остановить загрузку; вернуть наш, записать ADC1 и ADC2.
   Между этими показаниями не переезжать. Ничего не калибровать на промежуточной точке.
5. На штатном довести общий вес примерно до 2 т. Записать точную массу, например
   1985 кг, а не округлять до 2000. Вернуть наш, записать оба ADC ДО калибровки,
   выбрать ADC1 → 7228 → точная полная масса. Старый пустой ноль восстановится.
   После этого масштаб ADC1 рассчитан по двум точкам; ADC2 не меняется.
6. Оставить ADC1. На планшете выбрать следующий компонент по порядку → «Начать
   загрузку». Загружать оставшуюся порцию по планшету. Начальные 2 т не превращаются
   автоматически в выполненные компоненты: планшет учитывает только массу после
   «Начать загрузку». Для полного учёта замеса первые порции должны быть учтены
   отдельно; не выдавать этот частичный тест за полностью записанный рацион.
7. Пока ADC1 включён, завершить компонент на планшете. До отъезда остановить
   загрузку, записать общий ADC1, переключить ADC2 и записать, затем штатный.
   Сравнение на примерно 4 т — независимая проверка масштаба, в отличие от 2 т,
   на которых его только что настроили. При большом расхождении работать по штатному.

Не переключать профиль/калибровку внутри начатого компонента: tablet сравнивает
calibrationId начала и конца. Между завершённым компонентом и следующим началом
можно, но проще закончить настройку перед работой по планшету. После проверки
вернуть тот профиль, по которому будет идти дальнейшее взвешивание.

Записать таблицу: пусто / промежуточная масса / около 2 т до и после калибровки /
около 4 т. Колонки: штатный, ADC1 минимум–максимум, ADC2 минимум–максимум,
двигатель/мешалка, место. Шаг 5 кг не означает подтверждённую точность 5 кг.
